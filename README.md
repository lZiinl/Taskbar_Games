# Taskbar Games

**작업표시줄 위, 작은 오락실.**

과녁을 맞히고, 홈런을 날리고, 다람쥐와 잠깐 쉬어 가세요.

## 시작하기

1. 빌드된 **`bin\Taskbar_Games.exe`**를 실행합니다.
2. **모니터 선택창**에서 게임을 표시할 모니터 번호를 누릅니다.
3. 선택한 모니터의 작업표시줄 오른쪽 위에서 게임을 고릅니다.
4. 포트리스·야구·러너는 **CHAL(도전)** 또는 **PRACT(연습)**를 고릅니다. 다람쥐는 바로 실행됩니다.
5. 게임에서 **`Esc`**를 누르면 게임 선택창으로 돌아옵니다.

Windows 기본 .NET Framework를 사용하며 별도 패키지는 필요하지 않습니다. 실행 파일이 없다면 아래의 [빌드 방법](#개발하기)을 참고하세요.

| 선택창 | 왼쪽 | 오른쪽 |
| :--- | :---: | :---: |
| 위쪽 | 포트리스 | 야구 |
| 아래쪽 | 다람쥐 | 공룡 러너 |

모니터·게임·모드 선택창은 모두 **58×74픽셀**입니다. 모니터는 한 페이지에 4대까지 표시하며, 5대 이상이면 **NEXT**로 넘깁니다. 모니터 번호에 마우스를 올리면 장치 이름·작업 영역 크기·주 모니터 여부를 확인할 수 있습니다. 마지막 선택을 기억하지만 시작할 때마다 선택창을 표시합니다. 게임 선택창을 우클릭하면 모니터를 다시 선택하거나 **기록실 / 칭호**를 볼 수 있습니다. 모드 선택창의 **RECORD**에서도 기록실을 엽니다.

게임 선택창에는 게임 4개를 2×2로 배치하고 아래에 작은 **EXIT** 버튼을 두었습니다. 아이콘에 마우스를 올리면 이름과 조작 안내가 나타납니다. 게임은 한 번에 하나씩 실행됩니다.

모니터·게임·모드 선택, 결과창, 다람쥐 메뉴의 안내는 버튼을 가리지 않는 **왼쪽 검정·네온 설명 패널**로 표시합니다. 왼쪽 공간이 부족하면 위쪽에 표시합니다. **EXIT·BACK은 분홍색**, **CHAL은 노랑**, **PRACT는 초록**, **RECORD는 하늘색**으로 구분합니다.

> **프로그램 종료** — 선택창에서 `Esc` 또는 **EXIT**를 누르세요.

## 게임 소개

### 🎯 Fortress · 한 발의 거리 감각

스페이스바를 누른 시간만큼 힘을 모아 과녁을 맞히세요. 명중하면 과녁이 픽셀 조각으로 터지고, 연속 명중에는 콤보가 붙습니다.

| 조작 | 동작 |
| :--- | :--- |
| 탱크·점수판 클릭 | 게임 조작 시작 |
| `Space` 누르기 → 떼기 | 힘 충전 → 발사 |
| 탱크 우클릭 | 12색 팔레트에서 색상 선택 |
| `Esc` / 점수판 **×** | 게임 선택으로 돌아가기 |

최대 충전은 **2초**. 먼 과녁일수록 높은 점수를 주며 과녁 위에 이번 명중 점수가 표시됩니다. 연습에서는 빗나가도 같은 과녁을 다시 노릴 수 있습니다. 도전은 **10발 총점**으로 겨루며 매 발 새 과녁이 나옵니다. 다른 앱으로 전환하면 충전이 취소됩니다.

### ⚾ Baseball · 타이밍 하나로 홈런까지

투수가 던지는 공에 맞춰 스윙하세요. 정확하게 맞힐수록 멀리 날아가고, 130m 펜스를 넘으면 홈런입니다.

| 조작 | 동작 |
| :--- | :--- |
| 타자·점수판 클릭 | 투구 시작 |
| 타자 / 투수 우클릭 | 해당 선수의 KBO 구단 유니폼 선택 |
| `Space` 한 번 | 스윙 — 한 투구에 한 번 |
| `Esc` / 점수판 **×** | 게임 선택으로 돌아가기 |

**`PERFECT` → `GOOD` → `HIT`** 순으로 타격 정확도를 표시합니다. 비거리는 **12~160m**, 점수는 **1m당 10점**이며 공이 착지한 뒤 결과를 보여줍니다.

구속은 매번 **90~160km/h**로 바뀌며 투수 옆에 작게 표시합니다. 기존 최고 속도를 140km/h로 환산해 상한을 20km/h 높였고, 펜스 높이는 원래 높이의 **1.2배**입니다. 도전은 **10구 총점**, 연습은 투구 수 제한 없이 진행합니다. 점수판 오른쪽의 **LEFT**는 남은 공 수입니다.

다른 앱으로 전환하면 도전 모드는 투구와 예약된 스윙까지 그대로 일시 정지하고, 돌아오면 이어집니다. 연습 모드는 진행 중인 투구를 새로 준비합니다. 이미 친 공의 비행과 결과 화면은 두 모드 모두 일시 정지됩니다.

타자와 투수는 각각 KBO 10개 구단의 배색·모자·줄무늬를 살린 유니폼을 고를 수 있습니다. 선택 중에는 경기가 멈추며 구단 변경은 능력치나 기록에 영향을 주지 않습니다. 두 선수의 선택은 따로 저장됩니다. 구단 명칭은 [KBO 구단 소개](https://www.koreabaseball.com/kbo/league/teaminfo.aspx)를 기준으로 합니다.

선택창은 **3열×4행, 106×122픽셀**이며 팀명 없이 구단 로고만 표시합니다. 현재 선택은 초록 테두리로 표시하고, 마우스를 올리면 구단 이름을 확인할 수 있습니다. 로고는 실행 파일에 포함되어 인터넷 연결 없이 표시됩니다.

### 🐿️ Squirrel · 곁에 두는 작은 친구

작업표시줄을 천천히 산책하고, 쉬고, 낮잠을 자는 픽셀 동물 친구입니다. 다람쥐·강아지·고양이·판다 중 고르고 먹이를 놓아 주거나 쓰다듬어 주세요.

| 동물 | 먹이 |
| --- | --- |
| 다람쥐 | 도토리 |
| 강아지 | 뼈 간식 |
| 고양이 | 생선 |
| 판다 | 대나무 |

메뉴 아이콘·배치 미리보기·먹는 모션에 같은 먹이를 사용합니다. 동물을 바꾸면 이미 놓인 먹이도 함께 바뀌고 개수·포만감·식사 횟수는 유지됩니다.

| 조작 | 동작 |
| :--- | :--- |
| 다람쥐 클릭 | 쓰다듬기 |
| 다람쥐에 포커스를 준 뒤 `Space` | 폴짝 점프 · 누름 한 번에 한 번 |
| 다람쥐 우클릭 | 작은 아이콘 메뉴 열기 |
| 먹이 아이콘 → 원하는 위치 클릭 | 먹이 추가 · 가까운 것부터 찾아가 먹기 |
| 배치 중 `Esc` / 우클릭 | 먹이 배치 취소 |
| `Esc` / 메뉴의 **게임 선택으로 돌아가기** | 게임 선택으로 돌아가기 |

| 산책 | 쉬기 | 낮잠 |
| :---: | :---: | :---: |
| 2~4분 | 1~3분 | 3~5분 |

우클릭 메뉴는 **상태 · 먹이 · 쓰다듬기 · 낮잠 · 돌아가기 · 동물 변경** 아이콘 6개로 구성됩니다. 마지막 발바닥 아이콘에서 동물을 고를 수 있습니다. 마우스를 올리면 설명이 나타나고, 상태 아이콘에서는 포만감·기분·식사 횟수를 확인할 수 있습니다. 동물을 변경해도 돌봄 상태는 이어지며 선택은 다음 실행에도 유지됩니다.

산책 중 무작위로 **콜라 마시기·팝콘 먹기·책 읽기·TV 보기**와 동물별 전용 행동을 합니다. 간식 모션은 포만감·기분·식사 횟수를 바꾸지 않으며, 간식과 전용 행동은 1~2분, 독서·TV는 2~3분 유지한 뒤 산책으로 돌아갑니다. 첫 취미는 산책 시간 2분 뒤 시작하며, 이후에는 산책 시간을 2~4분 누적할 때마다 시작합니다. 먹이를 놓으면 취미 활동보다 먹이 찾기를 우선합니다.

| 동물 | 전용 행동 |
| :--- | :--- |
| 다람쥐 | 땅 파기 · 꼬리 손질 |
| 강아지 | 꼬리 흔들기 · 공 놀이 |
| 고양이 | 세수 · 식빵 자세 |
| 판다 | 대나무 먹기 · 배 두드리기 |

전용 행동 중에도 쓰다듬기·수면·점프가 가능합니다. 동물을 바꾸면 진행 중인 취미를 끝내고 산책으로 돌아갑니다.

다른 앱을 사용해도 산책은 이어집니다. 먹이는 바닥에 최대 5개까지 놓을 수 있으며 기존 먹이는 사라지지 않습니다. 5개가 있으면 먹이 아이콘이 잠시 비활성화됩니다. 동물은 가까운 것부터 찾아가 먹습니다. 먹는 도중 추가한 먹이는 현재 먹기를 마친 뒤 찾아갑니다. 먹으러 가는 중에도 쓰다듬거나 재울 수 있으며, 해당 행동이 끝나면 다시 가까운 먹이를 찾습니다. 배치 중에는 화면을 어둡게 덮지 않고 작은 먹이 미리보기만 표시합니다.

**부담 없이 돌보세요.** 방치해도 아프거나 떠나지 않으며, 프로그램을 꺼 둔 동안에는 상태가 줄어들지 않습니다. 포만감·기분·식사 횟수는 자동으로 저장됩니다.

### 🦖 Dino Runner · 선인장을 넘어 달리기

작은 픽셀 공룡이 **화면 왼쪽 절반**의 작업표시줄 위를 달립니다. 공룡·선인장·점수판은 눈에 덜 띄는 **흑백 테마**입니다. 장애물은 짧은 간격의 구간과 긴 회복 구간을 섞어 배치하고 너비도 달라집니다. 연습은 초당 140픽셀에서 180초에 걸쳐 최대 560픽셀까지 가속합니다. **도전은 처음부터 최고 속도 560픽셀/초로 120초 버티기**입니다. 다른 앱을 사용하는 동안에는 생존 시간이 늘지 않습니다.

| 조작 | 동작 |
| :--- | :--- |
| 공룡·점수판 클릭 | 게임에 포커스 주기 |
| `Space` | 시작·점프 |
| `Space` 짧게 / 길게 누르기 | 낮은 점프 / 높은 점프 |
| 충돌 후 `Space` | 다시 시작 |
| `Esc` / 점수판 **X** | 게임 선택으로 돌아가기 |

다른 앱으로 전환하면 일시 정지됩니다. **HI**는 저장된 최고 점수입니다. 게임 선택창으로 돌아가거나 프로그램을 다시 실행해도 유지됩니다.

## 기록과 설정

기록과 설정은 `%LOCALAPPDATA%\Taskbar_Games\profile.xml`에 함께 저장합니다.

- 공통: 연습·도전별 한 판 최고 기록, 도전 완료 횟수, 획득·장착한 칭호. 새 판은 점수와 횟수가 0부터 시작합니다.
- 러너: 최고 점수, 도전 최장 생존 시간과 성공 횟수. 달리던 중 종료해도 현재 기록까지 반영합니다.
- 야구: 한 판 최고 점수·안타·홈런 수, 전체 최고 비거리와 누적 점수·시도·안타 수. 착지한 결과만 저장합니다.
- 포트리스: 한 판 최고 점수·명중 수, 누적 발사·명중 수, 최고 콤보, 탱크 색상.
- 동물 친구: 선택한 동물, 포만감, 기분, 식사 횟수. 바닥에 놓인 먹이는 저장하지 않습니다.
- 선수 외형: 타자와 투수의 구단 유니폼 선택.
- 표시 설정: 마지막으로 선택한 모니터.

기존 `squirrel.txt`, 탱크 색상 레지스트리와 `tank-color.txt`는 처음 실행할 때 가져오며 원본은 보존합니다. 이전 프로필의 누적 기록도 유지되며 기록실에서 확인할 수 있습니다. 이전 러너 최고점은 연습 최고 기록으로 이전합니다. 저장 파일은 임시 파일을 거쳐 교체하고 이전 정상 파일은 `.bak`으로 보관합니다. 저장 오류도 **기록실 / 칭호**에서 확인할 수 있습니다.

### 도전 칭호

**점수와 횟수 모두 도전 한 판 기준**입니다. 여러 판의 횟수를 합산하거나 연습 기록으로 칭호를 획득할 수는 없습니다. 획득한 칭호는 영구 보관하지만 **자동으로 착용하거나 플레이 화면에 획득 알림을 띄우지 않습니다**. 직접 착용한 칭호만 점수판 부근에 작은 회색 글씨로 표시합니다.

기록실은 **174×148픽셀**입니다. 게임 이름 양옆의 **‹ / ›** 버튼이나 키보드 **← / →**로 이전·다음 게임을 볼 수 있습니다. 칭호를 선택한 뒤 **착용 / 해제**를 누릅니다. 착용 중은 **노란색**, 미해금은 **흰색**, 해금했지만 착용하지 않은 칭호는 초록색입니다. 목록의 네온 스크롤은 휠·화살표 클릭·막대 드래그를 지원하며 키보드 위아래·Home·End·Page Up/Down으로도 이동합니다.

기록이나 칭호에 마우스를 올리면 기록실 **왼쪽**에 검정 배경·네온 테두리·픽셀 제목의 설명 패널이 나타납니다. 다른 칭호를 가리지 않으며, 왼쪽 공간이 부족한 작은 화면에서는 기록실 위에 배치합니다.

기록 숫자에 마우스를 올리면 최고 기록별 **달성 날짜·시간**, 칭호에 올리면 **최초 획득 날짜·시간**도 표시합니다. 표시 형식은 `YYYY-MM-DD HH:mm:ss`이며 PC 현지 시간을 사용합니다. 동점이나 재저장으로 날짜가 바뀌지는 않습니다. 시각을 저장하지 않았던 이전 기록은 **기록 없음**으로 표시합니다.

도전 결과창은 게임 선택창과 같은 **58×74픽셀**입니다. 점수·명중·홈런 또는 생존 시간을 간략히 표시하고, **RETRY**로 재도전하거나 **BACK**으로 게임 선택에 돌아갑니다. 결과 숫자에 마우스를 올리면 상세 결과와 새로 획득한 칭호를 확인할 수 있습니다.

## 개발하기

프로젝트 루트에서 Windows PowerShell로 실행합니다.

```powershell
# 빌드 → bin\Taskbar_Games.exe
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1

# 빌드 및 화면 없는 로직 테스트 (기본)
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

실행 중인 게임을 종료한 뒤 빌드하세요. 기본 테스트는 게임 창을 띄우지 않습니다. 실제 창·포커스·화면 검사는 필요할 때만 `scripts/test.ps1 -IncludeUI`로 실행하며, 이때는 게임 창이 잠시 표시되고 테스트 화면이 `artifacts/tests/`에 생성됩니다.

기본 검증은 빌드와 화면 없는 게임 규칙·저장 회귀 테스트로 제한합니다. 별도 자동 클릭 검사나 모션별 이미지 비교는 실행하지 않고, 실제 사용감은 수동으로 확인합니다.

```text
Taskbar_Games/
├─ assets/          # 앱 아이콘
├─ src/
│  ├─ Launcher/     # 2×2 게임 선택창
│  ├─ Shared/       # 픽셀 글꼴 · 테마 · 색상 팔레트
│  └─ Games/        # Fortress · Baseball · Pet · Runner
├─ tests/           # 게임별 회귀 테스트
├─ scripts/         # 빌드 · 테스트 · 아이콘 생성
└─ docs/            # 상세 동작과 구현 참고
```

수치별 규칙, 설정 저장 위치, 갱신 방식은 **[상세 동작 및 개발 참고](docs/DETAILS.md)**에서 확인할 수 있습니다.

현재는 네 게임과 세 게임의 연습·도전 모드를 제공합니다. 다람쥐 미니퀘스트·모션 해금, 여러 게임의 동시 실행은 아직 포함하지 않습니다.
