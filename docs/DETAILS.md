# 상세 동작 및 개발 참고

[← Taskbar Games](../README.md)

게임별 수치와 저장 방식, 구현 구조를 정리한 문서입니다. 기본 조작은 README에서 확인하세요.

## 모니터 선택과 공통 저장

- 실행 순서는 **모니터 선택 → 게임 선택 → 모드 선택 → 게임 실행**입니다. 세 선택창 모두 58×74픽셀로 고정됩니다. 모니터가 하나여도 선택창을 표시합니다. 다람쥐는 모드 선택 없이 바로 실행합니다.
- 모니터 선택창은 장치 번호 아이콘을 2×2로 배치합니다. 5대 이상은 NEXT로 순환하며, Esc는 시작 단계에서 프로그램을 종료합니다. 게임 선택창의 우클릭 메뉴로 다시 모니터를 선택할 수 있고 이때 취소하면 기존 선택을 유지합니다.
- `DisplaySelection`이 선택한 장치 이름을 현재 화면 목록에 대응시킵니다. 모든 게임, 도토리 배치·표시, 탱크 팔레트가 같은 작업 영역을 사용합니다. 음수 좌표의 보조 모니터도 지원하며, 선택한 모니터가 분리되면 기본 모니터로 대체합니다. 도토리 배치 중 작업 영역이 바뀌면 해당 배치를 취소합니다.
- `GameStore`와 버전 3 `GameData`가 `%LOCALAPPDATA%\Taskbar_Games\profile.xml`을 소유합니다. 버전 1·2 프로필은 기존 기록과 설정을 보존하면서 이전합니다. 폼과 게임 모델은 파일이나 레지스트리를 직접 읽지 않습니다.
- 저장은 임시 파일 작성·디스크 flush 후 교체하며 이전 파일을 `.bak`에 남깁니다. 손상된 원본은 정상 백업에서 복구합니다. 원본과 백업을 모두 읽지 못하거나 더 새 버전이면 기존 파일을 덮어쓰지 않고 오류를 표시합니다.
- 기존 펫 파일과 탱크 색상은 새 프로필이 없을 때만 가져옵니다. 탱크 색상은 유효한 레지스트리 값을 우선하고, 없으면 실행 파일 옆 `tank-color.txt`를 사용합니다. 이전 원본은 삭제하지 않습니다.
- 게임 선택창의 우클릭 **기록실 / 칭호** 또는 모드 선택창의 **RECORD**에서 저장된 기록과 오류를 확인합니다. 기록 저장 실패가 게임 플레이를 종료시키지는 않습니다.

## 모드와 칭호

- **CHAL**은 도전, **PRACT**는 연습입니다. 연습은 횟수 제한이 없고, 도전은 포트리스 10발·야구 10구·러너 최고 속도 120초로 구성합니다. 도전 종료 후 결과창에서 재도전하거나 게임 선택으로 돌아갑니다.
- 게임 모델이 `RunStats`로 한 판의 결과를 제공하고, 판마다 생성한 `ProgressTracker`가 모드별 최고 기록·완료 횟수·전체 누적 기록·칭호를 공통 저장 계층에 반영합니다. 종료 시 같은 결과를 다시 보고해도 누적 기록이나 완료 횟수를 중복 계산하지 않습니다.
- 칭호는 도전 한 판의 점수·명중·홈런 횟수로만 판정합니다. 여러 판의 누적 횟수, 연습 기록, 이전 버전의 누적 기록으로 지급하지 않습니다. 조건을 충족한 즉시 저장하지만 자동 장착과 플레이 중 획득 알림은 없습니다. 직접 착용한 칭호만 점수판 부근에 회색 글씨로 표시합니다.
- 기록실은 테두리 없는 174×148픽셀 창입니다. 게임 이름 양옆의 이전·다음 버튼과 키보드 좌우 화살표로 양방향 순환합니다. 착용 중은 노란색, 미해금은 흰색, 해금 후 미착용은 초록색이며 선택 강조와 관계없이 색을 유지합니다.
- `ArcadeList`가 목록과 네온 스크롤을 직접 그립니다. 휠·위아래 화살표 클릭·트랙 페이지 이동·막대 드래그와 키보드 위아래·Home·End·Page Up/Down을 지원합니다. 스크롤만 움직이면 선택이나 착용 상태가 바뀌지 않습니다.
- 상세 기록·해금 조건·획득 일시·저장 오류는 `RecordInfoPopup`의 검정·네온 안내로 확인합니다. 실제 표시는 포커스를 받지 않는 `ToolStripDropDown`에 직접 그린 패널을 담아 사용합니다. 활성·비활성 상태 모두 포커스를 바꾸지 않으며 기록실 왼쪽 8픽셀 밖에 표시합니다. 왼쪽 공간이 부족하면 위쪽에 배치합니다. 목록 이탈·스크롤·게임 변경·창 숨김·닫기 시 안내를 명시적으로 닫습니다. 이전 버튼의 늦은 이탈 이벤트가 새 버튼의 안내를 닫지 않도록 표시 대상을 추적합니다.
- 모드별 최고 점수·히트·홈런·생존 시간과 전체 최고 비거리·콤보·러너 점수에는 각각 달성 시각을 저장합니다. 기존 값을 초과했을 때만 UTC 시각을 갱신하며 동점·재저장은 최초 시각을 보존합니다. 칭호는 최초 해금 시각만 저장합니다. 설명 패널에서 PC 현지 시간의 `yyyy-MM-dd HH:mm:ss`로 표시하며 구버전의 시각 없는 항목은 추정하지 않고 `기록 없음`으로 표시합니다.
- 결과창은 테두리 없는 58×74픽셀로 게임 선택창과 크기가 같습니다. 주요 결과는 픽셀 글꼴로 표시하고 상세 결과·새 칭호는 툴팁으로 제공합니다. RETRY·BACK 버튼과 Esc 복귀를 지원합니다.
- `ArcadeHints`는 모니터·게임·모드 선택, 기록실 이동 버튼, 결과창, 다람쥐와 아이콘 메뉴의 툴팁 디자인과 위치를 통일합니다. 메뉴 설명은 메뉴 전체 경계를 기준으로 배치하여 다른 버튼을 가리지 않습니다. 현재 안내의 원본 버튼에서 마우스가 이탈하거나 클릭·창 이동·창 숨김 시 닫고 창 종료 시 이벤트와 툴팁을 해제합니다. 이전 버튼의 늦은 이탈 이벤트는 다른 버튼의 새 설명을 닫지 않습니다.
- EXIT·BACK은 공통 `PixelMenuButton`으로 게임 선택창과 같은 분홍 글자·어두운 패널·1픽셀 테두리·52×12 크기를 사용합니다. 모드 버튼은 CHAL 노랑·PRACT 초록·RECORD 하늘색이며 호버나 포커스가 있어도 고유 글자색을 유지합니다.
- 포트리스·야구 점수 칭호는 각각 1,000·5,000·10,000점 이상일 때 지급합니다. 포트리스는 첫 명중·10명중, 야구는 10안타·첫 홈런·10홈런 칭호도 제공합니다. 러너의 120초 성공 칭호를 포함해 총 12개이며 이름은 README의 칭호 표에서 확인할 수 있습니다.
- 게임 화면에는 이번 판의 점수와 횟수만 표시합니다. 이전 기록은 모드별 기록실에서 확인하며, 게임을 도중에 닫아도 그때까지 확정된 최고 기록과 칭호는 유지됩니다. 완료 횟수는 도전 종료 조건을 충족해야 증가합니다.

## 다람쥐 펫

- 다람쥐 아이콘을 선택하면 선택한 모니터의 작업표시줄 위에서 픽셀 다람쥐가 산책하고, 두리번거리거나 낮잠을 잡니다. 다른 앱으로 이동해도 산책은 이어집니다.
- 다람쥐 몸체는 약 32×28픽셀이며, 우클릭 메뉴는 검정 배경과 형광 초록·청록색의 오락실 테마를 사용합니다. 선택창과 게임 점수판에도 같은 색 테마를 적용합니다.
- 다람쥐를 **왼쪽 클릭**하면 쓰다듬으며 기분이 올라갑니다. 반응에는 1.5초의 재사용 간격이 있습니다.
- 동물 **우클릭** 메뉴는 154×34픽셀의 아이콘 패널입니다. 상태·먹이·쓰다듬기·낮잠·돌아가기·동물 변경 아이콘을 제공하며, 마우스를 올리면 설명이 나타납니다. 상태 아이콘의 설명에는 포만감·기분·식사 횟수가 표시됩니다. 메뉴를 연 동안에는 움직임이 멈춥니다.
- `PetAppearance`는 다람쥐·강아지·고양이·판다의 귀·꼬리·얼굴 무늬를 구분해 그립니다. 동물 선택은 `PetAnimal` 설정에 저장되며 돌봄 상태를 초기화하지 않습니다. 기존 76×56 창 안에 TV와 소품까지 배치합니다.
- `PetBehavior`는 먹이 없는 산책 중 12~28초 간격으로 콜라·팝콘·독서·TV 중 하나를 고릅니다. 첫 활동은 산책 15초 뒤이며 간식은 7초, 독서·TV는 12초입니다. 끝나면 남은 산책을 이어갑니다. 이 활동은 `Feed()`를 호출하지 않으며 도토리·쓰다듬기·수면·점프 입력으로 중단할 수 있습니다.
- **먹이 아이콘**을 선택한 뒤 원하는 가로 위치를 클릭하면 작업표시줄 위에 먹이를 추가합니다. 전체 화면의 색은 바뀌지 않으며, 작은 먹이 미리보기만 표시됩니다. `Esc` 또는 우클릭으로 배치를 취소할 수 있습니다. 화면 양 끝은 접근 가능한 범위로 보정합니다.
- 먹이는 바닥에 최대 5개까지 놓을 수 있으며 기존 먹이를 덮어쓰지 않습니다. 여섯 번째 배치는 거부하고, 하나를 먹으면 다시 배치할 수 있습니다. 매 이동 단계에서 가장 가까운 먹이를 선택하고 도착 시 한 번만 섭취 처리합니다. 먹는 도중에도 추가 배치가 가능하며, 6초간 먹기 동작을 마치고 다음 먹이로 향합니다. 배치된 먹이는 게임 창을 닫으면 사라집니다.
- 자연스러운 행동 유지시간은 산책 2~4분, 쉬기 1~3분, 낮잠 3~5분입니다. 처음 실행하면 2분간 쉬며, 메뉴에서 재우면 5분간 쉽니다. 쓰다듬기 반응은 4초, 먹기는 6초간 이어집니다. 먹이를 찾으러 가는 중에도 쓰다듬기·낮잠을 실행할 수 있습니다. 사용자가 시작한 행동은 먹이보다 우선하며, 끝나거나 깨우면 다시 먹이를 찾아갑니다.
- 실행 중 포만감은 30초마다 1, 기분은 45초마다 1씩 감소합니다. 먹이는 포만감 22·기분 5를, 쓰다듬기는 기분 12를 회복합니다. 모든 수치는 0~100 범위이며 방치로 아프거나 떠나지 않습니다.
- 상태는 공통 `profile.xml`에 먹이를 먹을 때, 60초마다, 정상 종료 시 저장합니다. 프로그램을 꺼 둔 시간에는 수치가 감소하지 않습니다. 저장 오류는 우클릭 상태란에 표시합니다.
- 펫에 포커스가 있을 때 `Esc`를 누르거나 우클릭 메뉴의 **게임 선택으로 돌아가기**를 선택하면 선택창으로 돌아갑니다.
- 첫 버전은 기본 돌봄과 산책을 제공합니다. 미니퀘스트·모션 해금·다른 게임과 동시 실행은 아직 포함하지 않습니다.

## Baseball

- 구단 선택은 106×122픽셀 `ToolStripDropDown`에 32×28픽셀 로고 버튼을 3열×4행으로 배치합니다. 10개 구단과 빈칸 2개이며 팀명은 접근성 이름과 호버 설명에만 제공합니다. 로고 PNG는 `assets/teams/`에서 실행 파일 리소스로 포함합니다.
- 타자와 투수 우클릭은 각각의 `TeamUniform` 선택 메뉴를 엽니다. KBO 10개 구단의 배색과 도트 이니셜을 사용하며 LG에는 세로 줄무늬를 적용합니다. 메뉴가 열린 동안 시간 경과와 스윙을 막고 닫을 때 기준 시각을 갱신합니다. 선택은 `BatterTeam`, `PitcherTeam`에 별도로 저장하고 유효하지 않은 값은 기본 외형으로 표시합니다.
- 타자나 점수판을 클릭하면 투수가 준비 동작을 하고 공을 던집니다.
- **스페이스바를 한 번 누르면 스윙합니다.** 한 투구에는 한 번만 스윙할 수 있으며 키를 계속 누르고 있어도 자동으로 반복되지 않습니다.
- 공이 홈플레이트에 도착하기 직전에 스윙하세요. 타격 타이밍이 정확할수록 비거리가 늘어나며 `PERFECT`, `GOOD`, `HIT`로 표시됩니다.
- 투구 속도는 **90~160km/h**에서 균등 무작위로 정합니다. 기존 최고 속도(비행 1.05초)를 140km/h로 환산하고 상한을 20km/h 높였습니다. 비행 시간은 `1.05 × 140 / 구속`으로 계산해 약 **0.919~1.633초**이며 투구 중 현재 구속을 투수 오른쪽에 표시합니다. 도전의 남은 공 수는 점수판 오른쪽에 7픽셀 글꼴의 LEFT 라벨로 표시합니다.
- 유효한 타격은 **12~160m**까지 날아갑니다. **공이 착지한 결과 화면에서만 비거리·획득 점수·이번 판 총점·최고 비거리**를 표시합니다. 비행 중에는 거리나 예상 점수를 표시하지 않습니다. 점수는 **1m당 10점**이며 타이밍을 놓치면 0점입니다.
- 130m 지점에 펜스가 있습니다. 높이는 원래 논리 단위 18에서 **21.6으로 1.2배** 높였습니다. 물리 판정은 21.6을 사용하고 그림은 정수 좌표 22로 반올림합니다. 공이 펜스 상단을 완전히 넘으면 그 순간 `HOME RUN`이 표시되며, 점수와 홈런 수는 착지할 때 반영합니다. 낮은 타구가 펜스에 맞으면 안쪽 128m 지점으로 떨어지고 실제 착지 거리로 점수를 계산합니다.
- 비거리와 획득 점수는 착지한 공 바로 옆에 표시합니다. 오른쪽 공간이 부족하면 공 왼쪽에, 점수판과 겹치는 짧은 타구는 바로 위에 표시합니다. 결과가 1.4초간 표시된 후 다음 공이 나옵니다.
- 야구 선수·공·펜스의 표시 배율은 0.65로, 이전 0.9 배율보다 약 28% 작습니다. 선수 몸체는 약 26×31픽셀입니다. 타자의 발과 다리는 고정하고 상체 회전 → 타격 → 높은 팔로스루 → 복귀를 연속 동작으로 표시합니다. 투수는 가슴 앞에서 공과 글러브를 모은 뒤 팔꿈치를 접어 준비하고 공을 던집니다. 스페이스 입력부터 배트가 타격 지점에 도달하기까지 0.08초, 전체 스윙과 복귀는 0.46초입니다.
- 타자 옆 안내·점수 상자는 높이 18픽셀로 줄이고, 글자는 화면의 정수 픽셀에 그려 축소로 획이 빠지지 않게 합니다. 착지 결과와 펜스 표기도 글자를 축소하지 않아 획을 유지합니다. 긴 점수는 상자 너비가 자동으로 늘어납니다.
- 동작 참고: [MLB Network — Rhys Hoskins 스윙 분석](https://www.mlb.com/video/analyzing-hoskins-swing-x5813)의 준비·상체 회전·높은 마무리 자세를 참고하되, 하체는 게임에 맞춰 고정했습니다. 게임에 맞춰 직접 그린 픽셀 관절 애니메이션이며 영상 이미지 자체는 포함하지 않습니다.
- 다른 앱으로 전환하면 진행 중인 투구와 예약된 스윙을 취소합니다. 이미 친 공의 비행이나 결과 화면은 일시 정지했다가 돌아오면 이어집니다.
- 비활성 상태에서는 250ms 간격으로 작업 영역만 확인하며 반복해서 다시 그리지 않습니다.

도전은 헛스윙·놓친 공을 포함한 10구로 끝나며 11번째 투구를 만들지 않습니다. 한 판 최고 점수·안타·홈런 수는 모드별로 저장하고, 전체 누적 점수·최고 비거리·시도·안타 수도 보존합니다. 새 판은 0부터 시작하며 진행 중인 투구나 비행은 저장하지 않습니다.

## Fortress

- 탱크나 점수판을 클릭하면 게임에 키보드 포커스를 줍니다.
- 스페이스바를 누르면 힘이 충전되고, 떼면 25도 각도로 발사합니다. 최대 충전은 2초이며 최대 힘에서 유지됩니다.
- 명중하면 과녁이 도트 조각으로 터지고 다음 과녁이 나옵니다. 2회 연속 명중부터 콤보가 표시됩니다.
- 빗나가면 콤보가 초기화됩니다. 연습은 같은 과녁을 다시 노리고, 도전은 매 발 새 과녁으로 바뀝니다. 도전은 10발의 결과가 확정되면 종료합니다.
- 탱크를 우클릭하면 검정·형광 테마의 4×3 팔레트(92×82픽셀)에서 대표색 12개 중 하나를 고를 수 있습니다. 초록, 라임, 노랑, 주황, 빨강, 분홍, 보라, 파랑, 청록, 터쿼이즈, 흰색, 회색을 제공합니다. 색상 선택 중에는 게임이 일시 정지되고, `Esc` 또는 닫기로 취소합니다. 기존에 저장된 사용자 색은 새 색을 고를 때까지 유지됩니다.
- 다른 앱으로 이동하면 충전을 취소하고 키보드 입력을 넘깁니다.
- 게임에 포커스가 있을 때 `Esc`, 또는 점수판의 `X` 버튼으로 게임 선택창으로 돌아갑니다.

과녁은 탱크부터 화면 오른쪽 끝까지 거리의 10~80% 구간에 생성되며, 점수판과 겹치는 구간은 제외합니다. 과녁 가장자리와 점수판 사이에는 약 8픽셀의 여백을 둡니다. 다음 발사의 점수 자릿수 증가를 미리 고려해 조준 중에는 과녁이 움직이지 않습니다.

명중 점수는 `100 + 1900 × (과녁 거리 / 전체 사거리)`를 10점 단위로 반올림합니다. 비율은 0~1로 제한하며 현재 생성 범위에서는 대략 290~1,620점입니다. 같은 상대 거리라면 모니터 너비가 달라도 같은 점수를 받습니다. 과녁 위에 예상 명중 점수, 명중 결과에 획득 점수를 표시합니다.

충전·비행·파편 효과가 진행될 때는 16ms 간격으로 갱신합니다. 대기 중, 최대 충전 유지 중, 정적인 결과 표시 중에는 반복해서 화면을 다시 그리지 않습니다. 대기 중에도 작업 영역 변경 감지를 위해 250ms 간격으로 위치를 확인하고, 결과 표시가 끝날 때는 화면을 갱신합니다.

모드별 한 판 최고 점수·명중 수, 탱크 색상과 누적 명중·발사 수, 최고 콤보는 공통 프로필에 저장합니다. 발사·명중 결과·색상 변경·정상 종료 시 반영합니다. 새 판에서는 점수·발사·명중·콤보가 모두 0부터 시작합니다. 예전 `HKEY_CURRENT_USER\Software\TaskbarFortress`의 `TankColor`는 최초 이전에만 읽습니다.

## Dino Runner

- 화면 왼쪽 절반, 높이 100픽셀의 투명 창에서 실행합니다. 공룡 몸체는 약 30×27픽셀이며 게임 화면은 흑백입니다.
- 스페이스로 시작·점프하고, 짧게 떼면 낮게 점프합니다. 충돌 후 스페이스로 재시작합니다.
- 연습 속도는 실제 플레이 시간 180초에 걸쳐 140에서 최대 560픽셀/초(4배)까지 선형으로 증가합니다. 도전은 시작부터 560픽셀/초이며 충돌 없이 120초를 버티면 성공합니다. 일시 정지 중에는 가속·생존 시간이 진행되지 않습니다.
- 장애물 사이 빈 공간은 약 446~511픽셀의 조밀한 간격(확률 2/3)과 546~726픽셀의 회복 간격(확률 1/3)을 섞습니다. 최소 간격은 최고 속도에서 최대 점프 시간·착지 후 0.10초·추가 8픽셀을 기준으로 계산합니다. 장애물 너비는 11·20·28픽셀, 높이는 17~25픽셀로 달라집니다.
- 충돌과 점프는 240Hz 고정 시간 단계로 계산합니다. 30·60·144fps에서 충돌 결과를 검증합니다.
- 포커스를 잃으면 진행을 멈추고, 작업 영역이 바뀌면 코스를 초기화합니다. 최고 점수는 공통 프로필에서 복원하고 충돌·작업 영역 변경·정상 종료 시 저장합니다. 달리던 중 종료하면 현재 점수까지 최고 기록에 반영합니다.

## 빌드 및 검증

프로젝트 루트에서 Windows PowerShell로 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

테스트는 빌드 후 포트리스 전투·배치·갱신, 야구의 무작위 투구 범위·30/60/144프레임에서의 타격 판정·거리별 점수·입력 취소, 선택창의 위치·중복 게임 방지·복귀·종료를 확인합니다. 포트리스 전투와 펫 행동은 공개 모델 API로 검사하고, 창 배치와 입력 연결만 UI 통합 테스트로 확인합니다. 공통 테스트는 저장 왕복·이전·백업 복구·쓰기 실패·게임 재실행·5대 이상 모니터 페이지·음수 화면 좌표·모니터 분리를 검사합니다. 테스트용 저장은 `artifacts/tests/` 안에서만 수행하며 실제 사용자 설정은 읽거나 변경하지 않습니다. 화면 재현 결과는 `artifacts/tests/`에 저장합니다.

도전 테스트는 10발·10구 종료와 재시작, 거리 점수, 높아진 펜스와 홈런 가능성, 구속 범위, 모드별 저장, 한 판 기준 칭호와 중복 지급 방지, 버전 1 프로필 이전을 확인합니다. 러너는 12개 장애물 시드 × 2개 화면 너비 × 30·60·144fps에서 120초 완주 가능성과 정확한 종료 시간을 검사합니다. 모드 선택창·기록실·결과창과 각 게임 화면도 이미지로 생성합니다.

## 지원 범위

선택한 모니터의 작업 영역 아래쪽에 표시됩니다. 아래쪽 작업표시줄을 기준으로 설계했으며 자동 숨김·세로 배치에서는 작업 영역 아래쪽에 표시됩니다. 다른 일반 창 위에 유지되지만 전체 화면 전용 앱에서는 표시를 보장하지 않습니다. 화면 크기나 작업 영역이 변경되면 진행 중인 발사를 취소하고 배치를 다시 계산합니다.
