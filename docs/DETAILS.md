# 상세 동작 및 개발 참고

[← Taskbar Games](../README.md)

게임별 수치와 저장 방식, 구현 구조를 정리한 문서입니다. 기본 조작은 README에서 확인하세요.

## 다람쥐 펫

- 다람쥐 아이콘을 선택하면 기본 모니터의 작업표시줄 위에서 픽셀 다람쥐가 산책하고, 두리번거리거나 낮잠을 잡니다. 다른 앱으로 이동해도 산책은 이어집니다.
- 다람쥐 몸체는 약 32×28픽셀이며, 우클릭 메뉴는 검정 배경과 형광 초록·청록색의 오락실 테마를 사용합니다. 선택창과 게임 점수판에도 같은 색 테마를 적용합니다.
- 다람쥐를 **왼쪽 클릭**하면 쓰다듬으며 기분이 올라갑니다. 반응에는 1.5초의 재사용 간격이 있습니다.
- 다람쥐 **우클릭** 메뉴는 130×34픽셀의 아이콘 패널입니다. 상태·도토리·쓰다듬기·낮잠·돌아가기 아이콘을 제공하며, 마우스를 올리면 설명이 나타납니다. 상태 아이콘의 설명에는 포만감·기분·먹은 도토리 수가 표시됩니다. 메뉴를 연 동안에는 움직임이 멈춥니다.
- **도토리 아이콘**을 선택한 뒤 원하는 가로 위치를 클릭하면 작업표시줄 위에 먹이를 추가합니다. 전체 화면의 색은 바뀌지 않으며, 작은 도토리 미리보기만 표시됩니다. `Esc` 또는 우클릭으로 배치를 취소할 수 있습니다. 화면 양 끝은 접근 가능한 범위로 보정합니다.
- 도토리는 바닥에 최대 5개까지 놓을 수 있으며 기존 먹이를 덮어쓰지 않습니다. 여섯 번째 배치는 거부하고, 하나를 먹으면 다시 배치할 수 있습니다. 매 이동 단계에서 가장 가까운 도토리를 선택하고 도착 시 한 번만 섭취 처리합니다. 먹는 도중에도 추가 배치가 가능하며, 6초간 먹기 동작을 마치고 다음 도토리로 향합니다. 배치된 도토리는 게임 창을 닫으면 사라집니다.
- 자연스러운 행동 유지시간은 산책 2~4분, 쉬기 1~3분, 낮잠 3~5분입니다. 처음 실행하면 2분간 쉬며, 메뉴에서 재우면 5분간 쉽니다. 쓰다듬기 반응은 4초, 먹기는 6초간 이어집니다. 먹이를 찾으러 가는 중에도 쓰다듬기·낮잠을 실행할 수 있습니다. 사용자가 시작한 행동은 먹이보다 우선하며, 끝나거나 깨우면 다시 먹이를 찾아갑니다.
- 실행 중 포만감은 30초마다 1, 기분은 45초마다 1씩 감소합니다. 먹이는 포만감 22·기분 5를, 쓰다듬기는 기분 12를 회복합니다. 모든 수치는 0~100 범위이며 방치로 아프거나 떠나지 않습니다.
- 상태는 `%LOCALAPPDATA%\Taskbar_Games\squirrel.txt`에 먹이를 먹을 때, 60초마다, 정상 종료 시 저장합니다. 프로그램을 꺼 둔 시간에는 수치가 감소하지 않습니다. 저장 오류는 우클릭 상태란에 표시합니다.
- 펫에 포커스가 있을 때 `Esc`를 누르거나 우클릭 메뉴의 **게임 선택으로 돌아가기**를 선택하면 선택창으로 돌아갑니다.
- 첫 버전은 기본 돌봄과 산책을 제공합니다. 미니퀘스트·모션 해금·다른 게임과 동시 실행은 아직 포함하지 않습니다.

## Baseball

- 타자나 점수판을 클릭하면 투수가 준비 동작을 하고 공을 던집니다.
- **스페이스바를 한 번 누르면 스윙합니다.** 한 투구에는 한 번만 스윙할 수 있으며 키를 계속 누르고 있어도 자동으로 반복되지 않습니다.
- 공이 홈플레이트에 도착하기 직전에 스윙하세요. 타격 타이밍이 정확할수록 비거리가 늘어나며 `PERFECT`, `GOOD`, `HIT`로 표시됩니다.
- 투구 속도는 매번 달라지며, 공이 타격 지점까지 도착하는 시간은 **1.05~1.65초**입니다.
- 유효한 타격은 **12~160m**까지 날아갑니다. **공이 착지한 결과 화면에서만 비거리·획득 점수·누적 점수·최고 비거리**를 표시합니다. 비행 중에는 거리나 예상 점수를 표시하지 않습니다. 점수는 **1m당 10점**이며 타이밍을 놓치면 0점입니다.
- 130m 지점에 펜스가 있습니다. 공이 펜스 상단을 완전히 넘으면 그 순간 `HOME RUN`이 표시되며, 점수는 착지할 때 반영합니다. 낮은 타구가 펜스에 맞으면 안쪽 128m 지점으로 떨어지고 실제 착지 거리로 점수를 계산합니다.
- 비거리와 획득 점수는 착지한 공 바로 옆에 표시합니다. 오른쪽 공간이 부족하면 공 왼쪽에, 점수판과 겹치는 짧은 타구는 바로 위에 표시합니다. 결과가 1.4초간 표시된 후 다음 공이 나옵니다.
- 야구 선수·공·펜스의 표시 배율은 0.65로, 이전 0.9 배율보다 약 28% 작습니다. 선수 몸체는 약 26×31픽셀입니다. 타자의 발과 다리는 고정하고 상체 회전 → 타격 → 높은 팔로스루 → 복귀를 연속 동작으로 표시합니다. 투수는 가슴 앞에서 공과 글러브를 모은 뒤 팔꿈치를 접어 준비하고 공을 던집니다. 스페이스 입력부터 배트가 타격 지점에 도달하기까지 0.08초, 전체 스윙과 복귀는 0.46초입니다.
- 타자 옆 안내·점수 상자는 높이 18픽셀로 줄이고, 글자는 화면의 정수 픽셀에 그려 축소로 획이 빠지지 않게 합니다. 착지 결과와 펜스 표기도 글자를 축소하지 않아 획을 유지합니다. 긴 점수는 상자 너비가 자동으로 늘어납니다.
- 동작 참고: [MLB Network — Rhys Hoskins 스윙 분석](https://www.mlb.com/video/analyzing-hoskins-swing-x5813)의 준비·상체 회전·높은 마무리 자세를 참고하되, 하체는 게임에 맞춰 고정했습니다. 게임에 맞춰 직접 그린 픽셀 관절 애니메이션이며 영상 이미지 자체는 포함하지 않습니다.
- 다른 앱으로 전환하면 진행 중인 투구와 예약된 스윙을 취소합니다. 이미 친 공의 비행이나 결과 화면은 일시 정지했다가 돌아오면 이어집니다.
- 비활성 상태에서는 250ms 간격으로 작업 영역만 확인하며 반복해서 다시 그리지 않습니다.

## Fortress

- 탱크나 점수판을 클릭하면 게임에 키보드 포커스를 줍니다.
- 스페이스바를 누르면 힘이 충전되고, 떼면 25도 각도로 발사합니다. 최대 충전은 2초이며 최대 힘에서 유지됩니다.
- 명중하면 과녁이 도트 조각으로 터지고 다음 과녁이 나옵니다. 2회 연속 명중부터 콤보가 표시됩니다.
- 빗나가면 같은 과녁을 다시 노릴 수 있습니다. 콤보는 초기화됩니다.
- 탱크를 우클릭하면 검정·형광 테마의 4×3 팔레트(92×82픽셀)에서 대표색 12개 중 하나를 고를 수 있습니다. 초록, 라임, 노랑, 주황, 빨강, 분홍, 보라, 파랑, 청록, 터쿼이즈, 흰색, 회색을 제공합니다. 색상 선택 중에는 게임이 일시 정지되고, `Esc` 또는 닫기로 취소합니다. 기존에 저장된 사용자 색은 새 색을 고를 때까지 유지됩니다.
- 다른 앱으로 이동하면 충전을 취소하고 키보드 입력을 넘깁니다.
- 게임에 포커스가 있을 때 `Esc`, 또는 점수판의 `X` 버튼으로 게임 선택창으로 돌아갑니다.

과녁은 탱크부터 화면 오른쪽 끝까지 거리의 10~80% 구간에 생성되며, 점수판과 겹치는 구간은 제외합니다. 과녁 가장자리와 점수판 사이에는 약 8픽셀의 여백을 둡니다. 다음 발사의 점수 자릿수 증가를 미리 고려해 조준 중에는 과녁이 움직이지 않습니다.

충전·비행·파편 효과가 진행될 때는 16ms 간격으로 갱신합니다. 대기 중, 최대 충전 유지 중, 정적인 결과 표시 중에는 반복해서 화면을 다시 그리지 않습니다. 대기 중에도 작업 영역 변경 감지를 위해 250ms 간격으로 위치를 확인하고, 결과 표시가 끝날 때는 화면을 갱신합니다.

기존 탱크 색상과의 호환을 위해 설정은 `HKEY_CURRENT_USER\Software\TaskbarFortress`의 `TankColor` 값을 계속 사용합니다. 기존 `tank-color.txt` 파일이 실행파일 옆에 있으면 유효한 색상을 이전하고 저장에 성공한 뒤 삭제합니다.

## Dino Runner

- 화면 왼쪽 절반, 높이 100픽셀의 투명 창에서 실행합니다. 공룡 몸체는 약 30×27픽셀이며 게임 화면은 흑백입니다.
- 스페이스로 시작·점프하고, 짧게 떼면 낮게 점프합니다. 충돌 후 스페이스로 재시작합니다.
- 속도는 플레이 시간 1초마다 1.5픽셀/초씩 증가하며, 140에서 최대 280픽셀/초까지 올라갑니다. 장애물 사이의 빈 공간은 약 271~631픽셀 범위에서 무작위로 정합니다. 최소 간격은 최고 속도에서 전체 점프 시간과 착지 후 0.2초 여유, 추가 24픽셀을 기준으로 계산합니다.
- 충돌과 점프는 240Hz 고정 시간 단계로 계산합니다. 30·60·144fps에서 충돌 결과를 검증합니다.
- 포커스를 잃으면 진행을 멈추고, 작업 영역이 바뀌면 코스를 초기화합니다. 최고 점수는 현재 게임 창 안에서 재시작할 때 유지되며 디스크에는 저장하지 않습니다.

## 폴더 구조

```text
Taskbar_Games/
├─ src/
│  ├─ Program.cs                 # 진입점, 중복 실행 방지
│  ├─ Launcher/LauncherForm.cs   # 픽셀 선택창, 게임 실행·복귀
│  ├─ Shared/                   # 픽셀 글꼴·그리기, 키 상태
│  └─ Games/
│     ├─ Runner/                # 공룡 러너 화면 · 점프 · 충돌 · 점수
│     ├─ Fortress/
│     │  ├─ FortressGame.cs      # 포트리스 화면, 입력, 게임 진행
│     │  └─ Ballistics.cs        # 포트리스 탄도 계산
│     ├─ Pet/
│     │  ├─ PetGame.cs           # 다람쥐 화면, 산책, 돌봄 메뉴, 상태 저장
│     │  ├─ AcornPlacement.cs    # 먹이 위치 선택·표시
│     │  └─ PetSession.cs        # 포만감·기분 변화와 돌봄 규칙
│     └─ Baseball/
│        ├─ BaseballGame.cs      # 야구 화면, 선수 동작, 입력
│        ├─ BaseballSession.cs   # 투구, 타이밍 판정, 비거리, 점수
│        └─ BatterAnimation.cs   # 스윙 단계별 자세와 관절 애니메이션
├─ tests/
│  ├─ Fortress/                 # 명중, 콤보, 과녁 배치, 갱신
│  ├─ Baseball/                 # 타격 타이밍, 점수, 입력, 일시 정지
│  ├─ Launcher/                 # 단일 게임 실행, 복귀, 선택창 배치
│  └─ Pet/                      # 돌봄, 먹이 추적, 행동 유지, 팔레트
├─ scripts/
│  ├─ build.ps1
│  └─ test.ps1
├─ bin/                         # 빌드 결과 (Git 제외)
│  └─ Taskbar_Games.exe
├─ artifacts/                   # 테스트 화면 등 생성물 (Git 제외)
├─ .gitignore
└─ README.md
```

새 게임은 `src/Games/<게임 이름>/`과 `tests/<게임 이름>/`에 추가합니다. 빌드 스크립트는 `src` 아래의 모든 C# 파일을 포함합니다. `LauncherForm`에 선택 카드를 연결하고, 게임의 `Esc`와 종료 버튼에서 `Close()`를 호출하면 선택창 복귀와 자원 정리를 공통으로 처리합니다.

## 빌드 및 검증

프로젝트 루트에서 Windows PowerShell로 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

테스트는 빌드 후 포트리스 전투·배치·갱신, 야구의 무작위 투구 범위·30/60/144프레임에서의 타격 판정·거리별 점수·입력 취소, 선택창의 위치·중복 게임 방지·복귀·종료를 확인합니다. 사용자 색상 설정은 읽거나 변경하지 않습니다. 화면 재현 결과는 `artifacts/tests/`에 저장합니다.

## 지원 범위

기본 모니터의 작업 영역 아래쪽에 표시됩니다. 아래쪽 작업표시줄을 기준으로 설계했으며 자동 숨김·세로 배치에서는 작업 영역 아래쪽에 표시됩니다. 다른 일반 창 위에 유지되지만 전체 화면 전용 앱에서는 표시를 보장하지 않습니다. 화면 크기나 작업 영역이 변경되면 진행 중인 발사를 취소하고 배치를 다시 계산합니다.
