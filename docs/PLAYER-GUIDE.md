# Taskbar Games 사용 안내 · 0.3.0

## 실행

ZIP을 새 폴더에 풀고 `Taskbar_Games.exe`를 실행하세요.
게임 선택창의 아이콘을 누르면 기존 오프라인 게임을 바로 이용할 수 있습니다.
서버나 계정은 오프라인 플레이에 필요하지 않습니다.

## 친구들과 기록 경쟁

1. 게임 선택창을 우클릭하고 **온라인 / v0.3.0**을 선택합니다.
2. 운영자에게 받은 HTTPS 서버 주소를 입력합니다.
3. 처음에는 닉네임과 초대 코드를 입력한 뒤 **참가**를 누릅니다.
4. 게임을 고르고 **온라인 도전**을 누릅니다.
5. 완료 후 결과창에서 **BACK**으로 돌아오면 기록이 등록됩니다.
6. **순위**에서 상위 10명과 내 순위를 확인합니다.

온라인 창에서 시작한 경기만 등록됩니다. 예전 로컬 최고점은 업로드하지 않습니다.
결과창의 RETRY는 온라인 경기에서 비활성화됩니다. 온라인 창에서 새 경기를 시작하세요.
게임 중 Esc로 나가거나 화면 배치가 바뀌면 해당 온라인 경기는 등록하지 않습니다.
러너는 충돌도 경기 완료이며, 120초 생존에 성공하면 공동 1위가 될 수 있습니다.

서버 연결이 끊겨 등록에 실패했다면 온라인 창을 그대로 둔 채 **재등록**을 누르세요.
같은 경기 번호로 재전송하므로 순위가 중복 집계되지 않습니다.
재등록할 결과는 메모리에만 보관됩니다. 온라인 창/프로그램을 닫으면 미등록 결과는 사라집니다.
기존 로컬 기록은 별도로 저장됩니다.

## 업데이트

온라인 서버를 한 번 설정하면 앱 시작 때 새 버전을 확인합니다.
새 버전이 있으면 게임 선택창의 우클릭 메뉴에 **업데이트 있음 / 온라인**이 표시됩니다.
온라인 창의 **연결 / 확인**으로 수동 확인도 가능합니다.
**업데이트**는 운영자가 지정한 HTTPS 배포 페이지를 브라우저로 엽니다.

1. 새 ZIP을 다운로드합니다.
2. 게임을 종료합니다.
3. 새 폴더에 압축을 풀고 새 EXE를 실행합니다.
4. 정상 동작을 확인한 후 이전 실행 파일을 정리합니다.

자동 다운로드·덮어쓰기·재시작은 하지 않습니다.
기록과 계정은 EXE 폴더 밖에 있으므로 같은 Windows 사용자로 실행하면 이어집니다.
서버가 요구하는 버전보다 오래된 앱은 온라인 도전이 제한되지만 오프라인 게임은 계속 가능합니다.

## 기록과 계정

- 게임 기록: `%LOCALAPPDATA%\Taskbar_Games\profile.xml`
- 서버 주소와 계정: `%LOCALAPPDATA%\Taskbar_Games\online.xml`
- 로그인 토큰은 현재 Windows 사용자에게 묶여 암호화됩니다.
- 다른 PC에서 같은 계정을 사용하려면 운영자에게 복구 토큰을 요청하세요.
- 받은 토큰을 **초대/복구** 칸에 넣고 **계정 복구**를 누릅니다.
- 복구 토큰 발급 시 이전 PC의 토큰은 폐기됩니다. 동시 다중 PC 로그인 기능은 없습니다.
- 초대 코드, 복구 토큰, `online.xml`을 공개 게시하지 마세요.
